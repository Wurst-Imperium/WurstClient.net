## Changelog

- Fixed AimAssist, FeedAura, Killaura, and KillauraLegit aiming at slightly outdated coordinates when you or the target is moving.

- HighJump's Height setting no longer becomes very inaccurate at higher values.

- Changed various mixins to no longer override vanilla methods for better compatibility with other mods.

- Fixed TriggerBot with "Simulate mouse click" enabled leaving the attack button held down while you're in a vehicle.

- Fixed AutoSword under-estimating mace damage.

- Fixed AutoArmor selecting zero-armor items (e.g. carved pumpkins) if your base armor is set higher than normal.

- Fixed a bunch of different issues with AutoArmor and AutoSword when you have custom armor/weapon items from commands or datapacks.

- Fixed Freecam in "Apply input to: Camera" mode leaking input packets, making you dismount vehicles and move minecarts when you're just trying to move the camera. (Minecraft 26.3 and later versions only)

- You can now take panorama screenshots while in Freecam. ([/d/1754](https://wurstforum.net/d/1754))

- Fixed Sneak's Packet mode no longer doing anything (since Minecraft 25w16a / 1.21.6). ([#1163](https://github.com/Wurst-Imperium/Wurst7/issues/1163))

- Fixed TP-Aura waiting for the attack cooldown even when it's Speed slider isn't set to "auto".

- Fixed a crash when disconnecting from a server while NameProtect is enabled. ([/d/1764](https://wurstforum.net/d/1764))
