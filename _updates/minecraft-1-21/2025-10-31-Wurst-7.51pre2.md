## Changelog since Wurst 7.51pre1

- Removed the list of supported crops from AutoFarm's description.

- Fixed a crash when setting the name of a template in TemplateTool to something that is not allowed in filenames.

- AutoFarm and AutoMine will now disable each other, as they don't work correctly if enabled at the same time.

- Improved the positioning of the "Last Server", "Server Finder", and "Clean Up" buttons on the multiplayer screen.

- Fixed the "Last Server", "Server Finder", and "Clean Up" buttons not aligning correctly with the vanilla UI and moving around when you resize the Minecraft window. ([/d/1360](https://wurstforum.net/d/1360))

- Fixed the "Server Finder" and "Clean Up" buttons not fitting into the Minecraft window at its default 854x480 size. ([#273](https://github.com/Wurst-Imperium/Wurst7/issues/273))

- Improved tab navigation on the multiplayer screen: The "Last Server" button is now selected first when there is a last server to go back to.

- Pressing enter on the ServerFinder screen will now only start a search if the "Search" button is actually selected.

- Fixed a crash when joining / reconnecting to a server while using OpenWaterESP. ([#1234](https://github.com/Wurst-Imperium/Wurst7/pull/1234))

- Fixed a crash when joining / reconnecting to a server while using AutoLeave.

- Added a "Swing hand" setting to AutoFarm.

- Renamed the "Facing" setting in AutoLibrarian, BuildRandom, and TreeBot as well as the "Face anchors" setting in AnchorAura and the "Face crystals" setting in CrystalAura to "Face target".

- Made the descriptions of all the "Face target" settings more consistent and fully translatable.

- Added a "Face target" setting to AutoFarm.

- Added a "Check line of sight" setting to AutoFarm.

- AutoFarm can now harvest amethyst clusters and replant budding amethyst blocks, if they somehow get destroyed and you somehow obtain them in item form.

## Changelog since Wurst 7.50.3

- You can now individually toggle harvesting and replanting for each plant type in the AutoFarm settings.

- AutoFarm can now harvest and replant sweet berry bushes (efficiently by right clicking them). ([#906](https://github.com/Wurst-Imperium/Wurst7/issues/906), [/d/372](https://wurstforum.net/d/372), [/d/911](https://wurstforum.net/d/911), [/d/999](https://wurstforum.net/d/999), [/d/1174](https://wurstforum.net/d/1174), [/d/1337](https://wurstforum.net/d/1337))

- AutoFarm can now harvest amethyst clusters and replant budding amethyst blocks, if they somehow get destroyed and you somehow obtain them in item form.

- AutoFarm can now replant bamboo if it gets destroyed.

- AutoFarm can now replant cactus if it gets destroyed.

- AutoFarm can now replant kelp if it gets destroyed.

- AutoFarm can now replant sugar cane if it gets destroyed.

- AutoFarm can now take seeds from the Creative menu if used in Creative Mode.

- Added a "Swing hand" setting to AutoFarm.

- Added a "Face target" setting to AutoFarm.

- Added a "Check line of sight" setting to AutoFarm.

- Renamed the "Facing" setting in AutoLibrarian, BuildRandom, and TreeBot as well as the "Face anchors" setting in AnchorAura and the "Face crystals" setting in CrystalAura to "Face target".

- Made the descriptions of all the "Face target" settings more consistent and fully translatable.

- Added an "Include normal chests" checkbox to ChestESP, which allows you to turn off the ESP on normal chests while still keeping it enabled on other containers.

- ChestESP now also works with barrels, shulker boxes, and trapped chests from the Lootr mod.

- Improved the positioning of the "Last Server", "Server Finder", and "Clean Up" buttons on the multiplayer screen.

- Improved tab navigation on the multiplayer screen: The "Last Server" button is now selected first when there is a last server to go back to.

- Updated the Turkish translations. ([#1202](https://github.com/Wurst-Imperium/Wurst7/pull/1202))

- AutoFarm and AutoMine will now disable each other, as they don't work correctly if enabled at the same time.

- Pressing enter on the ServerFinder screen will now only start a search if the "Search" button is actually selected.

- Fixed AutoFarm not recognizing melon/pumpkin stems if they are already attached to a melon/pumpkin.

- Fixed AutoFarm being unable to harvest kelp if it's exactly 2 blocks tall.

- Fixed AutoFarm being unable to harvest cactus if it's only 1 block tall and has a cactus flower on top.

- Fixed AutoFarm's markers for replanting spots sometimes rendering up to 0.125 blocks away from where they are supposed to be.

- Fixed Radar not rotating the player arrow correctly. ([#1162](https://github.com/Wurst-Imperium/Wurst7/pull/1162))

- Fixed the "Disable/Enable Wurst" button on the statistics screen sometimes rendering at the wrong position. ([#1072](https://github.com/Wurst-Imperium/Wurst7/issues/1072), [#1168](https://github.com/Wurst-Imperium/Wurst7/pull/1168))

- Fixed a crash when setting the name of a template in TemplateTool to something that is not allowed in filenames.

- Fixed the "Last Server", "Server Finder", and "Clean Up" buttons not aligning correctly with the vanilla UI and moving around when you resize the Minecraft window. ([/d/1360](https://wurstforum.net/d/1360))

- Fixed the "Server Finder" and "Clean Up" buttons not fitting into the Minecraft window at its default 854x480 size. ([#273](https://github.com/Wurst-Imperium/Wurst7/issues/273))

- Fixed a crash when joining / reconnecting to a server while using OpenWaterESP. ([#1234](https://github.com/Wurst-Imperium/Wurst7/pull/1234))

- Fixed a crash when joining / reconnecting to a server while using AutoLeave.

- Removed the list of supported crops from AutoFarm's description.
