## Changelog since v7.51.4

- Freecam no longer freezes your real player in place. For example, if you enable Freecam while falling, you will now continue to fall and not get kicked/detected as floating.

- You can now control your player's movement while Freecam is active by changing the new "Apply input to" setting from "Camera" to "Player". You can even switch between the two modes while Freecam is active. **ProTip:** Set up a keybind that changes this setting when pressed.

- Made Freecam safer: It will now turn itself off when you take damage, controlled by a new "Disable on damage" checkbox.

- Made Freecam's movement speed more customizable: The old "Speed" slider is now split into two separate ones for horizontal and vertical speed. (The vertical speed is relative to the horizontal one and internally stored as a multiplier, so it updates automatically when you change the horizontal speed.)

- Likewise, Flight's vertical speed is now relative to its horizontal speed too, making it easier to adjust both speeds while maintaining the same ratio between them.

- You can now change Flight's and Freecam's speed while you are using it by simply scrolling your mouse wheel, so you don't even need to open the settings menu. (This is optional, controlled by a new "Scroll to change speed" checkbox.)

- And you won't need to open the menu to check your current Flight/Freecam speed either: It will now be displayed in your HackList by default. (This, too, can be turned off with a new checkbox, named "Show speed in HackList".)

- By default, Flight's vertical speed is now limited to 3.95 in Survival Mode, since higher speeds would cause you to take fall damage even with NoFall enabled (and because it's much easier to accidentally set those high speeds with the scroll wheel). This can be overridden with a new "Allow unsafe vertical speed" checkbox.

- If you don't like seeing the inside of your own head when enable Freecam, you now have an "Initial position" setting where you can choose to have the camera placed in front of or above your head instead.

- Fixed the issue that made Flight's "Slow sneaking" setting necessary and removed it. You can now sneak at much higher speeds (3.95 or 10, depending on your game mode) with no issues. ([#1266](https://github.com/Wurst-Imperium/Wurst7/pull/1266))

- Fixed ExtraElytra changing your pose from flying to sneaking if you use the height control option, interrupting your flight, especially if NoFall is enabled at the same time. Does this finally fix the dreaded NoFall + Elytra bug that everyone's been complaining about? You'll be the judge of that. But I can at least tell you that in my testing, this new version worked flawlessly even with "Allow elytra" enabled in NoFall's settings.

- Fixed Flight/Freecam causing a slight camera wobble when you sneak (especially noticeable at low speed). ([#1266](https://github.com/Wurst-Imperium/Wurst7/pull/1266))

- Fixed a few chunks sometimes turning invisible while in Freecam.

- Fixed flowing water being able to push your camera when using Freecam.

- Using both Flight and Freecam at the same with different speeds will now always use Freecam's speed.

- Fixed <kbd>space</kbd> and <kbd>shift</kbd> not cancelling each other out if you press both while using Flight, Freecam, or ExtraElytra.

- Improved the default values of Flight's Anti-Kick settings. The default distance is now 0.035m and the default interval is now 70 ticks.

- Re-added NoFall's minimum fall distance threshold and made it configurable, as Minecraft's `fallDistance` value is no longer broken in 1.21.11. Having this threshold makes NoFall harder to detect and fixes all kinds of weird and hard-to-describe movement bugs that can happen without it. And if you're ever on a 1.21.4 server (where `fallDistance` is broken), you can just set the sliders to zero to get back the old behavior.

- Made all of Flight's, Freecam's, and NoFall's settings translatable and wrote German translations for them.

- Tunneller can now keep tunneling while Freecam is enabled, as long as "Apply input to" is set to "Player".

- AutoFarm can now keep farming and BuildRandom can keep building while Freecam is enabled (regardless of "Apply input to" setting).

- `.tp`'s "Disable Freecam" setting is now turned off by default, as teleporting the player while Freecam remains active is no longer an issue.

- Freecam will now hide your hand or held item by default so that it doesn't get in way of what you're actually trying to look at. This is controlled by a new "Hide hand" checkbox in the settings.

- When "Scroll to change speed" is turned off, you can now scroll to change your selected hotbar item while using Freecam.

- Fixed scrolling while Freecam is active changing your vanilla Minecraft flight speed (regardless of "Scroll to change speed" value).

- Fixed AutoFish mcMMO mode getting stuck in boats again. ([#1067](https://github.com/Wurst-Imperium/Wurst7/issues/1067), [/d/818](https://wurstforum.net/d/818))

- Completely overhauled the Russian translations. ([#1278](https://github.com/Wurst-Imperium/Wurst7/pull/1278))

- If you want your game menu (pause screen) to look more vanilla-like, you now have the option for the "Wurst Options" button to be displayed in the statistics screen instead. The setting can be found in ClickGUI > UI Settings > Wurst Options > Location or in Navigator > Wurst Options > Location.

- Added a tooltip to the "Wurst Options" button.

- Fixed the narrator reading the "Wurst Options" button as "Options" instead of "Wurst Options".

- Fixed the fake player entities created by Blink and RemoteView not having the same attributes (e.g. scale) as the real player.

- If you enable .annoy with `.annoy <some_player>` and then use the same command again to disable it, that will now work instead of disabling and then immediately re-enabling .annoy. ([#1272](https://github.com/Wurst-Imperium/Wurst7/issues/1272), [#1282](https://github.com/Wurst-Imperium/Wurst7/pull/1282))

- AutoFarm can now harvest and replant sea pickles. ([#1239](https://github.com/Wurst-Imperium/Wurst7/issues/1239))

- Renamed AutoFarm's settings to consistently use "Sentence case" instead of "Title Case".

- Added a "Sea pickles" checkbox to BonemealAura.

- Renamed the "Automation level" setting in BonemealAura to "Take items from" to be consistent with other hacks.

- Replaced the Fast/Legit Mode in BonemealAura with more granular settings.

- Added a MultiMeal checkbox to BonemealAura: When checked, BonemealAura can use bone meal on multiple plants at once. (This was previously part of Fast mode.)

- Added a "Check line of sight" checkbox to BonemealAura. (This was previously part of Legit mode.)

- Added a "Face target" setting to BonemealAura. (Previous behavior was equivalent to Server in Legit mode and Off in Fast mode.)

- Added a "Swing hand" setting to BonemealAura. (Previous behavior was equivalent to Client in Legit mode and Off in Fast mode.)

- Added an "Always FastPlace" checkbox to BonemealAura. (This was previously always off.)

- Added a "Use while breaking" checkbox to BonemealAura. (This was previously always off.)

- Added a "Use while riding" checkbox to BonemealAura. (This was previously always off.)

- Renamed "Disable Wurst" to "DisableWurst", since feature names aren't supposed to have spaces. The space also made it impossible to change DisableWurst's settings through .commands, which is now fixed.

- Increased the default BonemealAura range to 5, matching AutoFarm's default range.

- Searching "bmaura" in Navigator will now find BonemealAura.

- Fixed BaseFinder checking blocks below bedrock and marking them as player bases if `minecraft:void_air` isn't added to the Natural Blocks list. ([/d/1452](https://wurstforum.net/d/1452))

- Increased `.tp`'s maximum range to 22 blocks by using the same trick that makes ArrowDMG/MaceDMG work. ([#1271](https://github.com/Wurst-Imperium/Wurst7/pull/1271))
