## Changelog

- **Fixed a vulnerability in Wurst's custom translation system that allowed malicious servers to detect Wurst's presence by sending a specially-crafted corrupted resource pack.**

- Fluids in X-Ray now look the same whether Sodium is installed or not. ([#1243](https://github.com/Wurst-Imperium/Wurst7/pull/1243), Minecraft 1.21.4 and later versions only)

- Updated the Polish translations. ([#1246](https://github.com/Wurst-Imperium/Wurst7/pull/1246))

- Added a `runClientWithMods` Gradle task for manual compatibility testing. ([#1244](https://github.com/Wurst-Imperium/Wurst7/pull/1244), Minecraft 1.21.4 and later versions only)

See also: [Wurst 7.51 changelog](/updates/wurst-7-51/), [Wurst 7.51.1 changelog](/updates/wurst-7-51-1/)
