## Changelog

- You can now individually toggle harvesting and replanting for each plant type in the AutoFarm settings.

- AutoFarm can now harvest and replant sweet berry bushes (efficiently by right clicking them). ([#906](https://github.com/Wurst-Imperium/Wurst7/issues/906), [/d/372](https://wurstforum.net/d/372), [/d/911](https://wurstforum.net/d/911), [/d/999](https://wurstforum.net/d/999), [/d/1174](https://wurstforum.net/d/1174), [/d/1337](https://wurstforum.net/d/1337))

- AutoFarm can now replant bamboo if it gets destroyed.

- AutoFarm can now replant cactus if it gets destroyed.

- AutoFarm can now replant kelp if it gets destroyed.

- AutoFarm can now replant sugar cane if it gets destroyed.

- AutoFarm can now take seeds from the Creative menu if used in Creative Mode.

- Added an "Include normal chests" checkbox to ChestESP, which allows you to turn off the ESP on normal chests while still keeping it enabled on other containers.

- ChestESP now also works with barrels, shulker boxes, and trapped chests from the Lootr mod.

- Fixed AutoFarm not recognizing melon/pumpkin stems if they are already attached to a melon/pumpkin.

- Fixed AutoFarm being unable to harvest kelp if it's exactly 2 blocks tall.

- Fixed AutoFarm being unable to harvest cactus if it's only 1 block tall and has a cactus flower on top.

- Fixed AutoFarm's markers for replanting spots sometimes rendering up to 0.125 blocks away from where they are supposed to be.

- Updated the Turkish translations. ([#1202](https://github.com/Wurst-Imperium/Wurst7/pull/1202))

- Fixed Radar not rotating the player arrow correctly. ([#1162](https://github.com/Wurst-Imperium/Wurst7/pull/1162))

- Fixed the "Disable/Enable Wurst" button on the statistics screen sometimes rendering at the wrong position. ([#1072](https://github.com/Wurst-Imperium/Wurst7/issues/1072), [#1168](https://github.com/Wurst-Imperium/Wurst7/pull/1168))
