## Changelog

- Added AttributeSwap: Quickly swaps items when you attack, allowing you to save durability on your weapon or do a variety of different PVP techniques. ([#1333](https://github.com/Wurst-Imperium/Wurst7/pull/1333), [#1305](https://github.com/Wurst-Imperium/Wurst7/issues/1305), [#1275](https://github.com/Wurst-Imperium/Wurst7/issues/1275), [/d/982](https://wurstforum.net/d/982), [/d/1004](https://wurstforum.net/d/1004), [/d/1177](https://wurstforum.net/d/1177), [/d/1402](https://wurstforum.net/d/1402), [/d/1456](https://wurstforum.net/d/1456), [/d/1471](https://wurstforum.net/d/1471), [/d/1493](https://wurstforum.net/d/1493), [/d/1501](https://wurstforum.net/d/1501))

- Fixed the game crashing on startup when Better Block Entities version 1.3.2 or 1.3.3 is installed. However, Opacity X-Ray will still not work when using those BBE versions. ([/d/1583](https://wurstforum.net/d/1583), [#1340](https://github.com/Wurst-Imperium/Wurst7/issues/1340), [/d/1591](https://wurstforum.net/d/1591))

- Fixed NoSlowdown not letting you start sprinting during item use unless AutoSprint is also enabled.

- Fixed NoShieldOverlay no longer lowering the shield while blocking. ([/d/1556](https://wurstforum.net/d/1556))

- NoShieldOverlay now also supports custom shield items from datapacks (e.g. swords on some PVP servers).

  ![screenshot of NoShieldOverlay lowering a custom sword that has the blocking animation](https://i.imgur.com/O0lG4uS.png)

- Added automated tests for NoShieldOverlay to make sure the above two changes don't break in the future.

- Fixed Follow, Protect, and RemoteView no longer being able to detect when the entity they are following/protecting/viewing no longer exists, e.g. after you got kicked and reconnected.

- Fixed NoFog no longer removing edge-of-world fog when Sodium is installed. ([/d/1556](https://wurstforum.net/d/1556))

- Fixed Fullbright in Night Vision mode not working when BadOptimizations is installed.

- The "Filter pets" setting used in various hacks now handles all of the weird pets too.

- Fixed "Filter pets" settings getting fooled by the fake `tamed` flag that wild camels have. Instead, camels now count as pets if they have a saddle equipped.

- Skeleton horses are still considered pets if tamed, even though they'll usually self-tame when you walk up to them for the first time. This is because, unlike camels, the `tamed` flag on skeleton horses actually works (and works a little too well, see [MC-102949](https://bugs.mojang.com/browse/MC/issues/MC-102949)), so it's good to know when that flag is missing.

- Pigs and striders now count as pets if they have a saddle equipped, instead of never being pets just because they don't use the normal taming system.

- Foxes and ocelots now count as pets if they trust someone, instead of never just because they don't use taming.

- Happy Ghasts now count as pets.

- Added automated tests for the "Filter passive water mobs", "Filter babies", and "Filter pets" settings, so the next time Mojang changes the (very inconsistent and confusing) rules for how these mobs work, it shouldn't just quietly break the filters.
