## Changelog

- Fixed tracers (the "Lines" option in ItemESP, MobESP, PlayerESP, ChestESP, PortalESP and the "Tracer" option in Freecam) becoming much wider than they should be if the mob/player/etc. that a tracer points to is almost directly behind you. ([#1130](https://github.com/Wurst-Imperium/Wurst7/issues/1130))

- Fixed the message "Mod wurst uses the version ... which isn't compatible with Loader's extended semantic version format" appearing in the log file. ([#1120](https://github.com/Wurst-Imperium/Wurst7/issues/1120))

See also: [Wurst 7.47 changelog](/updates/wurst-7-47/)

## Known Issues in 1.21.5

- The LSD hack doesn't work and trying to enable it kicks you from the current world or server. LSD's post-processing shader has been updated to the new format required by 1.21.5, but the new format is simply broken on Minecraft's side so it won't work.

- When starting the game, you see a log message along the lines of `Failed to parse post chain at wurst:post_effect/lsd.json, list is too long: 16, expected range [0-4]`. This is the same LSD shader issue as above. The shader needs a `matrix4x4` uniform, which are supposed to be of length 16, but Minecraft now limits all uniforms to a length of 4 which makes using `matrix4x4` uniforms impossible.

- X-Ray mostly works, but it doesn't hide blocks like grass and snow correctly.

- At the time of writing, there is no Fabric Rendering API (FRAPI) in 1.21.5, so this version of Wurst was built without support for it. Please make sure to use the recommended Fabric API version below to avoid issues. Newer Fabric API builds may include FRAPI, which, in this version of Wurst, will cause X-Ray to stop working completely and might also prevent the game from launching.
