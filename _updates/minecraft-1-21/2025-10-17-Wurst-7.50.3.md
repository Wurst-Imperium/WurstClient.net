## Changelog

- **Patched a fingerprinting vulnerability in Minecraft that allows a malicious server to track you across different Minecraft accounts.** ([#1226](https://github.com/Wurst-Imperium/Wurst7/issues/1226))

- Fixed Wurst's HUD elements not rendering when debug hitboxes (F3 + B) are enabled. ([#1220](https://github.com/Wurst-Imperium/Wurst7/issues/1220), [/d/1314](https://wurstforum.net/d/1314), [/d/1336](https://wurstforum.net/d/1336))

- Improved a mixin used by the zoom feature for better compatibility with other zoom mods. ([#1218](https://github.com/Wurst-Imperium/Wurst7/issues/1218), [#922](https://github.com/Wurst-Imperium/Wurst7/issues/922), [#823](https://github.com/Wurst-Imperium/Wurst7/issues/823))

- The license file is now once again called `LICENSE-Wurst-Client.txt` instead of `LICENSE-property(java.lang.String, fixed(class java.lang.String, Wurst-Client)).txt`.

- Fixed NoLevitation not working in Minecraft 1.21.4/8/9/10. ([#1224](https://github.com/Wurst-Imperium/Wurst7/issues/1224), [/d/1226](https://wurstforum.net/d/1335))

- Fixed the LSD shader not working in Minecraft 1.21.9/10.

- Bumped the OpenGL versions of all of Wurst's shaders from `150` to `330` in Minecraft 1.21.9/10.

See also: [Wurst 7.50 changelog](/updates/wurst-7-50/), [Wurst 7.50.1 changelog](/updates/wurst-7-50-1/), [Wurst 7.50.2 changelog](/updates/wurst-7-50-2/)
