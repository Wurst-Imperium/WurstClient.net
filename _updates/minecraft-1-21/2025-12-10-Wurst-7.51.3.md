## Changelog

- Updated X-Ray to support Sodium version 0.8.0 for Fabric 1.21.11.

- Fixed X-Ray not hiding blocks like tall/short grass and snow layers properly.

- Added snow layers to the X-Ray test images.

- X-Ray will most likely break again once FRAPI (the Fabric Rendering API) gets updated to 1.21.11. To avoid issues, please only use this Wurst version with Fabric API version 0.139.4+1.21.11 (linked below).

See also: [Wurst 7.51 changelog](/updates/wurst-7-51/), [Wurst 7.51.1 changelog](/updates/wurst-7-51-1/), [Wurst 7.51.2 changelog](/updates/wurst-7-51-2/)
