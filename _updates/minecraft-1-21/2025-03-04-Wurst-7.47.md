## Changelog

- Completely overhauled the rendering of AirPlace, AntiAFK, AutoBuild, AutoFarm, AutoFish, AutoLibrarian, BaseFinder, BowAimbot, BuildRandom, CaveFinder, ChestESP, ClickGUI, Excavator, FeedAura, FightBot, Follow, Freecam, .goto, ItemESP, Killaura, KillauraLegit, MobESP, MobSpawnESP, Navigator, NewChunks, Nuker, NukerLegit, Overlay, .path, PlayerESP, PortalESP, ProphuntESP, Protect, Search, TabGUI, Trajectories, TreeBot, Tunneller, and VeinMiner to use the latest version of Minecraft's rendering API, which will be required in 1.21.5.

- The lines drawn by AirPlace, AntiAFK, AutoBuild, AutoFarm, AutoFish, AutoLibrarian, BaseFinder, BowAimbot, BuildRandom, ChestESP, Excavator, FeedAura, FightBot, Follow, Freecam, .goto, ItemESP, Killaura, KillauraLegit, MobESP, MobSpawnESP, NewChunks, Nuker, NukerLegit, Overlay, .path, PlayerESP, PortalESP, ProphuntESP, Protect, Trajectories, TreeBot, Tunneller, and VeinMiner are now (usually) 2 pixels wide and are no longer anti-aliased. (Note: Due to bugs in Minecraft's line rendering code, line width can sometimes be inconsistent. Hopefully this is still better than not having line width at all.)

- Minecraft's narrator feature can now read the selected alt in AltManager, the selected keybind or profile in Keybind Manager, the selected book offer in AutoLibrarian's "Wanted books" setting, the selected file in AutoBuild's "Template" setting, the selected block in any BlockListSetting, and the selected item in any ItemListSetting.

- Wurst's list screens (X-Ray blocks, Keybind Manager, etc.) now look more like Minecraft's own list screens.

- The block breaking animation of Excavator and Tunneller are no longer slightly different from the block breaking animation in other hacks.

- TemplateTool will no longer severely lag the game for a few seconds when creating a large template.

- TemplateTool will now show a preview of the selected area in the same way that Excavator does.

- Added Turkish language support with 298 strings translated. ([#1114](https://github.com/Wurst-Imperium/Wurst7/pull/1114))

- Added 122 strings to the Polish translations. ([#1093](https://github.com/Wurst-Imperium/Wurst7/pull/1093))

- Updated 28 strings in the Russian translations. ([#949](https://github.com/Wurst-Imperium/Wurst7/pull/949))

- Fixed the "Filter passive mobs" and "Filter passive water mobs" settings no longer filtering out squids, glow squids, and dolphins, as well as Radar no longer showing these mobs in the color for passive mobs. ([#1123](https://github.com/Wurst-Imperium/Wurst7/pull/1123), [/d/951](https://wurstforum.net/d/951))

- Fixed AntiSpam no longer adding counters to repeated messages. ([#1127](https://github.com/Wurst-Imperium/Wurst7/pull/1127))

- Fixed tooltips in Navigator ignoring the "Tooltip opacity" setting.

- Fixed Trajectories not rendering correctly when you are very far away from spawn.

- Fixed tracers (the "Lines" option in ItemESP, MobESP, PlayerESP, ChestESP, PortalESP and the "Tracer" option in Freecam) not rendering correctly in second person view (a.k.a. third person front view).

- Fixed the preview in AutoBuild and Excavator being visible through other blocks when it wasn't supposed to be.

- Fixed Excavator's scanning animation moving along the wrong axis.

- Fixed AutoSteal causing a mod conflict with Lightweight Inventory Sorting and Nemo's Inventory Sorting. ([/d/972](https://wurstforum.net/d/972))

- Fixed a crash when pressing the delete key in Keybind Manager while the list of keybinds is empty. ([#1124](https://github.com/Wurst-Imperium/Wurst7/issues/1124))
