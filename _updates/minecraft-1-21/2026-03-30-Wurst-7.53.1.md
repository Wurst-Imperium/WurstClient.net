## Changelog

- Updated X-Ray to work with Sodium 0.8.7 (Minecraft 26.1).

- Updated X-Ray to work with Sodium 0.8.7 while keeping backwards compatibility with Sodium 0.8.6 (Minecraft 1.21.11). ([#1320](https://github.com/Wurst-Imperium/Wurst7/issues/1320))

- (Still waiting for FRAPI, no X-Ray changes there.)

- Fixed Navigator's "New Keybind" screen still not accepting mouse buttons for keybinds.

- Fixed Navigator's "New Keybind" screen still not displaying keys the same way as in Minecraft's controls menu.

- Fixed various entity range checks in Wurst not matching how Minecraft itself would calculate them. ([/d/1547](https://wurstforum.net/d/1547))

- Fixed AntiWaterPush not working in Minecraft 26.1.
