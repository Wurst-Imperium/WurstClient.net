## Changelog

- Fixed Block and BlockList settings (e.g. the X-Ray Ores list) silently removing modded blocks when you restart the game. ([/d/1289](https://wurstforum.net/d/1289), [/d/1293](https://wurstforum.net/d/1293))

- As a result of the above fix, if you add a modded block to e.g. X-Ray Ores, then uninstall that mod and restart the game, the block will now stay there.

- Block and BlockList settings are now generally less strict about which blocks are considered invalid when loading the settings.json file. When they do remove a block, they will now always log an error message telling you which block was removed and why.

- Fixed Block and BlockList settings as well as the `.setblock` / `.blocklist` commands not rejecting invalid blocks correctly.

See also: [Wurst 7.50 changelog](/updates/wurst-7-50/)
