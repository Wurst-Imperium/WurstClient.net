## Changelog

- Fixed some chunks being invisible while you're in Freecam with Sodium mc26.2-0.9.1-beta.3 or later installed (Minecraft 26.2 and later versions only).

- Dropped support for Sodium versions older than mc26.2-0.9.1-beta.3 (Minecraft 26.2 and later versions only).

- Fixed a bug that made it impossible to turn the camera while in Freecam if Shoulder Surfing Reloaded is installed. ([#10 (WI Freecam)](https://github.com/Wurst-Imperium/WI-Freecam/issues/10), [#78 (WI Freecam)](https://github.com/Wurst-Imperium/WI-Freecam/issues/78))

- Fixed Blink & RemoteView no longer working in 26.2 ([/d/1658](https://wurstforum.net/d/1658), Minecraft 26.2 and later versions only).

- Added a very basic smoke test for Blink so it won't go unnoticed if it breaks like that again.

- Fixed AutoFarm not harvesting sugar cane growing on grass blocks, podzol, mycelium, moss blocks, or mud. ([/d/1661](https://wurstforum.net/d/1661), Minecraft 26.1 and later versions only).

- Fixed AutoFarm not replanting sweet berry bushes that were planted on grass blocks, podzol, mycelium, moss blocks, or mud. (Minecraft 26.1 and later versions only).

- Improved AutoFarm compatibility with data packs that change valid planting surfaces. (Minecraft 26.1 and later versions only).

- Fixed ChestESP no longer highlighting shulker boxes from the Lootr mod when "Include shulkers" is enabled.

- Added two automated tests for ChestESP: One to ensure each group (e.g. shulker boxes) still matches the intended blocks after a Minecraft/Lootr update, and one to visually verify the ESP lines/boxes still render correctly.

- Fixed ESP boxes (e.g. in ChestESP) appearing more opaque than they should be (Minecraft 26.2 and later versions only).
