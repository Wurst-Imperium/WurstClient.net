## Changelog

- Improved compatibility with other mods that modify the pause menu. This should fix a crash when using Lunar Client and also makes ModMenu's "replace mode" work properly. ([#54](https://github.com/Wurst-Imperium/Wurst7/issues/54), [#435](https://github.com/Wurst-Imperium/Wurst7/issues/435), [#633](https://github.com/Wurst-Imperium/Wurst7/issues/633), [#1018](https://github.com/Wurst-Imperium/Wurst7/issues/1018), [#1025](https://github.com/Wurst-Imperium/Wurst7/issues/1025), [#1057](https://github.com/Wurst-Imperium/Wurst7/issues/1057), [/d/102](https://wurstforum.net/d/102), [/d/592](https://wurstforum.net/d/592), [/d/605](https://wurstforum.net/d/605), [/d/609](https://wurstforum.net/d/609), [/d/615](https://wurstforum.net/d/615), [/d/756](https://wurstforum.net/d/756), [/d/862](https://wurstforum.net/d/862), [/d/959](https://wurstforum.net/d/959), [/d/1113](https://wurstforum.net/d/1113))

- Improved Compatibility with Sinytra Connector: The 1.21.1 version of Wurst now requires Fabric API >=0.107.0 instead of >=0.110.0.

- Fixed `.modify` and `.viewcomp` not working for some component types, for example enchantments. ([#1137](https://github.com/Wurst-Imperium/Wurst7/pull/1137))

- Backported changes from the past 7 months to Minecraft 1.20.1 (excluding `.viewcomp` and `.modify` changes, as item components don't exist in 1.20.1).

- Backported changes from the past 4 months to Minecraft 1.21.1.
