Wenn ich versuche den Fabric-Installer zu starten, bekomme ich eine Fehlermeldung die sagt dass ich kein Java habe.

Das bedeutet (selbstverständlich) dass du kein Java installiert hast. Du kannst Java von Adoptium herunterladen. Die Seite sollte automatisch die richtige Version für dein Betriebssystem anzeigen, aber falls nicht, such nach einer Version wo "JDK 21 - LTS" steht.
